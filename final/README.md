# Final Secure File Management System

## Overview

This directory contains the final integrated implementation of the Secure File Management System.

Unlike the individual task implementations, this version combines every feature into a single application.

## Included Features

- Task 0 – User Authentication
- Task 1 – XOR Encryption
- Task 2 – Encrypted File Creation
- Task 3 – Reading Encrypted Files
- Task 4 – Appending to Encrypted Files
- Task 5 – Logging File Operations
- Task 6 – Secure File Deletion

## Technologies Used
- C
- GCC
- OpenSSL (SHA-256)
- WSL (Windows Subsystem for Linux)

## Compile
 gcc file_encryption_system.c -o output


## Notes

This version integrates all project tasks into a single application with a menu-driven interface, allowing authenticated users to perform secure file management operations.
